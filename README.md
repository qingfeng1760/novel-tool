# 小说工具

只在你自己电脑上运行的小说收集与阅读工具：**书架、抓取、导入、阅读、追更**全在一个本地网页里。
数据全部存在本机 `data/` 目录，不上传任何地方，也不需要联网（除了抓取你主动填的站点）。

## 快速开始

需要 Node.js 20 或更高版本。

```bash
# Windows：双击「启动.bat」（会自动打开浏览器）
# 或命令行：
npm install
npm start
```

服务只监听 `127.0.0.1`，默认端口 `8618`，被占用会自动顺延并在控制台打印实际地址。
浏览器打开 <http://127.0.0.1:8618> 即可。

> **数据位置**：`data/` 目录（书库、索引、阅读进度、暂存与回收站），可以整个拷走迁移。
> 该目录不入库（见 `.gitignore`），删除前记得先备份。

## 三条加书路径

「加书」弹层里选一条就行：

1. **贴链接抓取** —— 粘贴小说目录页网址，工具整本抓下来，之后还能定时检查更新
2. **传文件导入** —— 把 TXT 拖进来，自动识别编码（乱码一键还原）、自动分章
3. **粘贴正文** —— 从网页复制正文直接粘贴，同样自动分章入库

## 抓取控制台

抓取是一条流水线，每一步都要你点头才往下走：

```
贴目录页链接 → 合规自检 → 结构探测 → 试抓确认 → 整本抓取 → 抓取报告
```

- **合规自检**：遵守站点 `robots.txt`，明确声明自己的身份，不做浏览器伪装、不携带 Cookie；
  不通过就没有「强行继续」的入口
- **结构探测**：可视化确认章节结构，认不出来时列出页面里的候选区让你点选
- **试抓**：先抓一章确认正文干净再开抓
- **整本抓取**：三色进度（已抓 / 待抓 / 失败），支持暂停、继续、取消、重试；
  抓取参数可调并发与同域间隔

## 其他功能

| 功能 | 说明 |
|---|---|
| 书架 | 分堆浏览（在读 / 追更中 / 已读完 / 全部），封面墙 + 更新角标，书名即时过滤 |
| 阅读器 | 独立阅读页，阅读进度 / 书签 / 笔记 / 时长统计 |
| 目录体检 | 目录完整性检查、更新对比、手工调章 |
| 检索 | 书名/作者搜索、筛选、重名合并 |
| 定时追更 | 追更配置、定时检查、更新通知 |
| 浏览器脚本 | `userscript/小说工具.user.js`：在任意网页右下角浮窗一键把当前章节存进本机书库；服务没启动时先暂存在浏览器，服务一起来自动补交 |
| 备份 | 「备份.bat」或 `node server/backup-cli.js` 导出备份，导入可恢复 |

浏览器脚本只与 `127.0.0.1` / `localhost` 上的本机服务通信，不往任何别的地方发数据。

## 运行测试

```bash
npm test                          # 跑全部阶段测试（当前 211 项）
node tools/run-tests.js s3 s4     # 只跑指定阶段
```

测试分 S0~S10 十一个阶段：骨架、数据模型、导入、书架、阅读器、章节、检索、抓取、
浏览器脚本、定时追更、设置。测试用临时数据目录，不碰你的真实书库。

## 目录结构

```
├─ server/                 服务端（原生 http，无框架）
│  ├─ index.js             入口：装配上下文 → 起服务 → 开浏览器 → 注册定时追更
│  ├─ app.js               路由装配、统一响应体、全局错误兜底
│  ├─ routes/              接口（books / chapters / fetch / import / reader / …）
│  ├─ services/            业务逻辑（抓取、导入、书架、章节、备份、合规…）
│  │  ├─ fetcher/          抓取管线：HTTP 客户端、域限流、通用网页解析
│  │  └─ adapters/         存储适配层（预留云端实现）
│  ├─ schema/              数据模型与迁移
│  └─ lib/                 基础设施（路由、静态、multipart、编码、路径…）
├─ web/                    网页前端（单页应用 + 独立阅读页）
├─ userscript/             油猴脚本
├─ tests/                  S0~S10 测试
├─ tools/                  生成 .bat 启动脚本、统一跑测试
├─ 启动.bat / 备份.bat      Windows 双击入口
└─ data/                   本地数据（不入库）
```

## 环境要求

- Node.js ≥ 20
- Windows 下双击 `.bat` 需要系统代码页 GBK（脚本由 `tools/make-bat.js` 按 GBK 生成，保证中文不乱码）
